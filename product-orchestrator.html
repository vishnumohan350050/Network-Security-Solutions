Network Security Orchestrator

The brain of network security — translating vendor-neutral policy into network-wide enforcement.

● Available

Overview

The Network Security Orchestrator provides the API layer that makes network security services programmable. It acts as the policy enforcement point, translating vendor- and technology-neutral policies into vendor-specific configurations, and integrates with the Policy Server, IoT NMS, Network Edge and Threat Sharing Platform to keep policy enforcement consistent across every device and edge environment.

It speaks multiple southbound protocols and runs in standalone or distributed mode, scaling from a single node to large, distributed deployments — with real-time telemetry for continuous visibility.

Key Capabilities

  • Southbound support for NETCONF, RESTCONF, gNMI and SNMP
  • Standalone or distributed deployment, scaling to large environments
  • Integrates policy enforcement across NMS, Edge, Policy Server and TSP
  • Real-time network telemetry for faster issue detection
