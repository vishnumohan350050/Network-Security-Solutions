Network Security Orchestration and Programmable Security Solution

The brain of network security — translating vendor-neutral policy into network-wide enforcement.

● Available

Overview

The Network Security Orchestrator provides the API layer that makes network security services programmable. It acts as the policy enforcement point, translating vendor- and technology-neutral policies into vendor-specific configurations, and integrates with the Policy Management System, IoT NMS, Network Edge and Threat Sharing Platform to keep enforcement consistent across every device and edge environment.

It speaks multiple southbound protocols and runs in standalone or distributed mode, scaling from a single node to large, distributed deployments — with real-time telemetry for continuous visibility.

Key Capabilities

  • Southbound support for NETCONF, RESTCONF, gNMI and SNMP
  • Standalone or distributed deployment, scaling to large environments
  • Event management, network topology and configuration management
  • Policy server integration with compliance-score calculation in the Southbound Library
  • SSH-based discovery and traffic analysis
  • Real-time network telemetry for faster issue detection
