Network Edge Solution

A programmable, high-performance edge platform securing last-mile IoT devices on commodity hardware.

● Available — hardware offloading enabled

Overview

Network Edge is a secure, centrally orchestrated software-based programmable IoT network edge platform that deploys on Commercial Off-The-Shelf (COTS) hardware, purpose-built to address the security and performance challenges of last-mile IoT devices.

A modular pipeline framework enables customizable, high-performance packet processing with kernel-bypass technologies — DPDK and XDP. The orchestrator connects over a gRPC interface, secured with ChaCha20-Poly1305 AEAD encryption over a WireGuard tunnel, so every session stays authenticated and encrypted end to end.

Key Capabilities

  • Modular pipeline with DPDK / XDP kernel-bypass packet processing
  • gRPC link to the orchestrator, secured with ChaCha20-Poly1305 AEAD + WireGuard
  • Built-in Service Function Chain (SFC), firewall and NAT
  • IPEncap / IPDecap and WireGuard-based VPN
  • Quality of Service (QoS) for traffic management and routing mechanisms
  • Hardware-based offloading of features
