TinyML IoT Hardware Platform

Edge-AI hardware bringing on-device intelligence and secure communication to the extreme edge of the IoT network.

● Two variants in development

Overview

The TinyML-enabled IoT hardware platform supports on-device intelligence, secure communication and low-power operation for IoT network security use cases — bringing machine learning to resource-constrained devices at the extreme edge.

Two variants are planned: the VEGA ET1031 (32-bit RISC-V) based THEJAS32, and a 64-bit ARM SoC based platform. Both integrate multi-sensor support, a full communication stack, an on-board cryptographic security module and NPU acceleration for on-device ML.

Key Capabilities

  • VEGA ET1031 (32-bit RISC-V) THEJAS32, and 64-bit ARM SoC variants
  • WiFi, BLE, Ethernet and 4G/5G connectivity with multi-sensor support
  • On-board cryptographic module (ATECC608C) and Trusted Platform Module
  • NPU acceleration and Over-the-Air (OTA) update support
